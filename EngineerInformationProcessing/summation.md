## 01. 요구사항 확인 (Software Design)
소프트웨어 개발의 첫 단추 고객의 요구를 어떻게 분석하고 문서화할 것인가가 핵심
- 요구사항 개발 프로세스: 도출 → 분석 → 명세 → 확인. 이 순서를 외우세요.
- DFD(Data Flow Diagram) 구성 요소: * Process(프로세스): 원(○). 데이터의 변환.
    - Data Flow(데이터 흐름): 화살표(→).
    - Data Store(데이터 저장소): 평행선(=).
    - External Entity(외부 엔티티): 사각형(□).
- CASE(Computer Aided Software Engineering): 소프트웨어 개발 과정의 일부 또는 전체를 자동화하기 위한 도구입니다. 주요 기능으로는 그래픽 지원, 소프트웨어 생명주기 전 단계 연결 등이 있습니다.
- UML(Unified Modeling Language): 객체지향 소프트웨어 설계 시 사용하는 표준화된 모델링 언어입니다.
    - **사물(Things), 관계(Relationships), 다이어그램(Diagrams)**으로 구성됩니다.
    - 관계: 연관, 집합(독립적), 포함(종속적), 일반화(상속), 의존, 실체화.

## 02. 화면 설계 (UI Design)
사용자와 시스템 간의 접점을 설계하는 파트입니다.
- UI 유형: * CLI(Command Line): 텍스트 기반.
    - GUI(Graphical User): 아이콘, 마우스 기반.
    - NUI(Natural User): 신체 부위, 음성 인식 기반.
    - VUI(Voice User): 목소리 인터페이스.
- UI 설계 원칙: * 직관성: 누구나 쉽게 이해.
    - 유효성: 정확하게 목표 달성.
    - 학습성: 누구나 쉽게 배움.
    - 유연성: 요구사항을 최대한 수용하고 오류 최소화.
- 프로토타이핑(Prototyping): 실제 개발 전 주요 기능을 시뮬레이션할 수 있는 모형을 만드는 것입니다.

## 03. 데이터 입출력 구현 (Data I/O)
데이터베이스의 논리적, 물리적 설계를 다룹니다.
- 데이터 모델의 3요소: 구조(Structure), 연산(Operation), 제약 조건(Constraint). (구연제!)
- 관계 데이터 모델:
    - 튜플(Tuple): 행(Row), 카디널리티(Cardinality).
    - 애트리뷰트(Attribute): 열(Column), 차수(Degree).
- 무결성 제약 조건: * 개체 무결성: 기본키는 NULL이 될 수 없고 중복될 수 없음.
    - 참조 무결성: 외래키는 참조하는 테이블의 기본키값과 동일하거나 NULL이어야 함.
    - 도메인 무결성: 속성값이 정의된 도메인 범위 내에 있어야 함.
- 이상 현상(Anomaly): 삽입, 삭제, 갱신 이상. 데이터 중복으로 인해 발생합니다.

## 04. 통합 구현 (Interface & Integration)
서로 다른 시스템을 어떻게 연결할 것인지가 관건입니다.
- EAI(Enterprise Application Integration): 기업 내 각종 애플리케이션 간 상호 연동.
    - Point-to-Point: 1:1 연결.
    - Hub & Spoke: 중앙 허브를 통한 집중형.
    - Message Bus: 미들웨어를 두어 확장성 보장.
    - Hybrid: 허브와 버스 방식 혼합.
- ESB(Enterprise Service Bus): 서비스 중심 아키텍처(SOA)를 지원하는 통신 인프라. 미들웨어를 통해 서비스 간의 결합도를 낮춥니다.
- JSON vs XML:
    - JSON: 속성-값 쌍. 텍스트 기반. 자바스크립트 객체와 유사. 가볍다.
    - XML: 마크업 언어. 태그를 이용해 데이터 구조 표현. 확장성이 좋지만 무겁다.

## 05. 서버 프로그램 구현 (Architecture & Framework)
백엔드 로직의 구조와 패턴을 다룹니다.
- 모듈화의 목표: 결합도는 낮추고(Loose Coupling), 응집도는 높인다(Strong Cohesion).
- 공통 모듈 설계 원칙: 정확성, 명확성, 완전성, 일관성, 추적성.
- 디자인 패턴(GoF): 앞서 설명했듯 생성(5), 구조(7), 행위(11) 패턴의 특징을 각각 매칭해서 외워야 합니다. 특히 **싱글톤(Singleton)**은 단 하나의 인스턴스만 생성한다는 것을 잊지 마세요.
- MVC 패턴: Model(데이터), View(화면), Controller(제어)를 분리하여 유지보수를 용이하게 함.

06. 프로그래밍 언어 활용 (Core Logic)실기 시험에서 가장 높은 배점(40~50점)을 차지하는 구간입니다.
- C언어: 포인터($*$), 주소($\&$), 구조체, 배열의 인덱스 계산.
    - int *p = '&a'; 코드가 나오면 p는 a의 주소를 담고, *p는 a의 값을 의미함을 명심하세요.
- Java: 클래스, 상속(extends), 인터페이스(implements), 생성자, 오버로딩 vs 오버라이딩.
    - 오버로딩: 같은 이름 메서드, 매개변수 다름.
    - 오버라이딩: 부모 메서드 재정의.
- Python: 슬라이싱(list[start:end:step]), 리스트 내포, range() 함수.
    - 예: a = [1, 2, 3, 4, 5], print(a[1:4:2]) 결과는 [2, 4]입니다.

## 07. SQL 응용 (Query & Procedure)
- DML 상세: * SELECT DISTINCT: 중복 제거.
    - GROUP BY와 HAVING: 그룹화와 그룹에 대한 조건.
    - JOIN: INNER, LEFT/RIGHT OUTER, FULL OUTER JOIN의 차이점 명확히 하기.
- 절차형 SQL: * 프로시저(Procedure): 호출을 통해 실행되는 일련의 SQL 작업.
    - 트리거(Trigger): 이벤트(Insert, Update, Delete)가 발생할 때 자동으로 실행.
    - 사용자 정의 함수: 프로시저와 유사하나 반드시 결과를 리턴함.

## 08. 애플리케이션 테스트 관리 (Quality Assurance)
소프트웨어의 결함을 찾고 신뢰성을 확보하는 과정입니다.
- 테스트 레벨: 단위 테스트 → 통합 테스트 → 시스템 테스트 → 인수 테스트(사용자 관점).
- 화이트박스 테스트: 내부 로직 검사. (구문, 결정, 조건 커버리지).
- 블랙박스 테스트: 기능 검사. (동등 분할, 경계값 분석, 원인-효과 그래프).
- 상향식 통합: 하위 모듈부터. 드라이버(Driver) 필요.
- 하향식 통합: 상위 모듈부터. 스텁(Stub) 필요. (스하! 하향식은 스텁!)

## 09. 소프트웨어 개발 보안 구축 (Cyber Security)
안전한 코딩과 인프라 보안을 다룹니다.
- 보안의 3요소: 기밀성(Confidentiality), 무결성(Integrity), 가용성(Availability). (기무가!)
- 공격 기법: * DoS/DDoS: 시스템 자원 고갈 공격.
    - SQL Injection: 입력창에 악의적인 SQL문을 삽입하여 DB 탈취.
    - XSS(Cross Site Scripting): 웹 페이지에 악성 스크립트를 삽입하여 사용자 정보 탈취.
    - 사회공학: 사람의 심리적 취약점을 이용.
- 암호화: * 대칭키: AES, SEED, ARIA.
    - 비대칭키: RSA(소인수분해 기반), ECC(타원곡선 기반).
    - 해시: SHA-256, HAS-160.

10. 제품 소프트웨어 패키징 (Deployment)
개발 완료 후 사용자에게 전달하는 과정입니다.
- 릴리스 노트: 소프트웨어의 수정 사항, 개선 사항 등을 명시한 문서.
- 디지털 저작권 관리(DRM): 불법 복제 방지 및 저작권 보호 기술.
    - 구성: 콘텐츠 제공자, 분배자, 패키저, 클리어링 하우스, 소비자.
- 버전 관리 도구: * 공유 저장소 방식: CVS, SVN.
    - 분산 저장소 방식: Git.

11. 정보시스템 구축 관리 (IT Management)
프로젝트 관리와 신기술 동향입니다.
- 소프트웨어 생명주기(SDLC): 폭포수, 나선형(계획→위험분석→개발→평가), 프로토타입, 애자일 모델.
- 비용 산정 모델: * 하향식: 전문가 감정, 델파이 기법.
    - 상향식: LoC(Line of Code), COCOMO(보통, 준정밀, 정밀), Putnam(생명주기 예측), FP(기능 점수).
- 신기술 용어: 블록체인, 클라우드(IaaS, PaaS, SaaS), 빅데이터, 인공지능, 디지털 트윈 등.
